# 嵌字工作台 · manga-lettering-workbench

漫画嵌字的工作台：按书、按页跟踪进度，每页有状态、7 项核查清单、备注、原图/成品图，另有待确认事项清单和嵌字规矩参考。嵌字本身仍在聊天里按规矩做，这里只收文件和记进度。

## 打开方式

启用 GitHub Pages 后打开 `https://<用户名>.github.io/manga-lettering-workbench/` 即可用；也可以直接下载 `index.html` 用浏览器打开。只有一个文件，不依赖任何服务器和外部资源。

## 数据存在哪里

数据只存在你自己的浏览器里（localStorage），不经过任何服务器。**每个人打开看到的都是自己浏览器里的数据，互不相通。** 换浏览器、换设备、清缓存都会看不到之前的数据。

所以请经常点页面底部的「导出备份（JSON）」，把备份存好；换设备时用「导入备份」恢复。

浏览器本地存储约 5–10 MB，原图 PNG 一张就可能占满。存不下时会提示：改传压缩过的预览图，或只记进度、不存原图。

## 预置内容

- 书目「第二本漫画」：1–10 页，状态均为「未开始」。口径：保留原图字形 100%，只加深原字颜色或调对比度；填色改色、字体重排路线已废弃；不得改动人物颜色。
- 待确认事项一条：「底图必须用最初下载的无损原版」。
- 规矩：格式规范、翻译流程、本地嵌字步骤、第二本漫画现行口径、本地环境清单（manga-ocr / OpenCV inpaint / LaMa / Noto Sans SC）。

## 功能

- 上传原图（可多选，自动按顺序排页）、加一页占位、上传/替换翻译文档
- 点开页卡：改状态（未开始 / 处理中 / 待核查 / 待确认 / 已完成）、逐项打勾 7 项核查清单、写备注、传原图 / 成品图、删页
- 新建一本书、删除整本书
- 待确认事项：新增、打勾确认、删除

## 发布

仓库根目录只有 `index.html` 与本文件。GitHub 仓库 Settings → Pages → Build and deployment → Source 选 Deploy from a branch，Branch 选 `main`、目录选 `/ (root)`，保存后等一两分钟即可访问。
